# Nuevo repositorio local creado

Para no seguir tocando el proyecto original, se creó una copia completa con Git independiente en:

- `/workspace/simulacion-poisson-trafico-red-v2`

## Qué se hizo

1. Se copió el contenido del proyecto actual.
2. Se eliminó el historial Git original de la copia.
3. Se inicializó un repositorio nuevo.
4. Se creó un commit inicial con el estado actual del proyecto.

## Comandos para publicar en GitHub (opcional)

Dentro de `/workspace/simulacion-poisson-trafico-red-v2`:

```bash
git branch -M main
git remote add origin <URL_DE_TU_REPO_NUEVO>
git push -u origin main
```

Con esto, puedes continuar el desarrollo en el repositorio nuevo sin modificar el original.
